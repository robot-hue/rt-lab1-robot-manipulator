# Лабораторная работа №1 по СРВ

Классификация систем реального времени и расчёт требуемого времени реакции.
Вариант: **«Робот-манипулятор»**.

Консольное приложение на Python 3.10+ (разработано на 3.12). Внешние библиотеки нужны только для тестов (`pytest`).

## Что делает программа

- классифицирует задачи по жёсткости (жёсткое / твёрдое / мягкое);
- определяет класс системы: жёсткого РВ, если есть хотя бы одна жёсткая задача, иначе мягкого;
- определяет тип дедлайна: неявный (D = T), ограниченный (D ≤ T), произвольный (D > T);
- считает запас L = D − C и признак выполнимости L ≥ 0;
- находит критическую задачу (минимальный L среди жёстких);
- считает требуемое время реакции R_треб = min(D) по жёстким задачам, а если их нет, по всем;
- считает загрузку U = Σ(Cᵢ / Tᵢ) и проверяет U ≤ 1;
- определяет архитектуру: однопроцессорная, многопроцессорная или распределённая;
- выводит таблицу задач и текстовое заключение.

## Запуск

```
py src/main.py -i data/variant.json
```

Без параметра `-i` берётся `data/variant.json`. Справка: `py src/main.py --help`.
На Linux и macOS вместо `py` используйте `python3`.

## Формат входного файла (JSON)

```json
{
  "system": { "n_cpu": 1, "has_network": false },
  "tasks": [
    { "name": "Управление приводами", "hardness": "жёсткое", "C": 1, "D": 4, "T": 5 }
  ]
}
```

- `n_cpu` — число процессоров (целое, не меньше 1);
- `has_network` — есть ли сеть (`true` или `false`);
- `hardness` — `жёсткое`, `твёрдое` или `мягкое` (регистр и «ё/е» не важны);
- `C`, `D`, `T` — время выполнения, относительный срок и период в мс, строго больше нуля.

## Основные функции (`src/main.py`)

| Функция | Назначение |
|---|---|
| `slack(task)` | запас L = D − C |
| `is_feasible(task)` | L ≥ 0 |
| `deadline_type(task)` | тип дедлайна по D и T |
| `classify_system(tasks)` | класс системы: жёсткого или мягкого РВ |
| `critical_task(tasks)` | жёсткая задача с минимальным L |
| `required_reaction_time(tasks)` | R_треб = min(D) |
| `utilization(tasks)` | U = Σ(Cᵢ / Tᵢ) |
| `classify_architecture(n_cpu, has_network)` | архитектура системы |
| `load_variant(path)` | чтение и проверка JSON |

## Допущения

- Если сеть есть, система считается распределённой, даже при одном процессоре.
- Условия L ≥ 0 и U ≤ 1 только необходимые. Проверка планируемости (RM, EDF) в этой работе не выполняется.
- В категорию «ограниченный (D ≤ T)» попадают случаи D < T, потому что D = T определяется раньше как «неявный».
